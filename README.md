# 🧠 Quizzes
Live link - <your live link, e.g. https://your-username.github.io/Quizzes/>

> Test your knowledge, one question at a time!

A simple, lightweight web app where users can take quizzes, answer questions and see their score at the end. Built with plain **HTML, CSS and JavaScript** — no frameworks or build tools required.

---

## ✨ Features

- **Take a quiz** made of multiple-choice questions
- Useful details for each question:
  - Question text
  - Answer options
  - Correct answer checked automatically
- **Instant feedback** after each answer
- **Score tracking** with a final result screen
- **Restart** the quiz and try to beat your score
- Clean, simple interface that works in the browser

## 🚀 Getting Started

No installation is needed.

1. **Clone the repository**

   ```bash
   git clone https://github.com/Aryanraj072001/Quizzes.git
   cd Quizzes
   ```

2. **Open the app**

   Double-click `index.html`, or open it from your browser (File → Open).

   Optionally, serve it locally with any static server, for example:

   ```bash
   # Python
   python -m http.server 8000
   ```

   Then visit `http://localhost:8000`.

## 💡 How to Use

1. Click **Start Quiz** to begin.
2. Select an answer for each question.
3. See your score on the result screen.
4. Click **Restart** to play again.
